## Options public sales page

Public route:

```text
/trading-systems/options
```

The route is now a commercial Options product page with the customer flow:

```text
Offer
→ Product Preview
→ What’s Included
→ Results
→ Subscription
→ FAQ
```

The protected subscriber/viewer route remains:

```text
/trading-systems/options/viewer
```

The public redesign does not replace or weaken that protected viewer.

### Offer and CTA contract

The page presents Options as a `$49/month` single-system product with daily website updates.

The primary paid-plan CTA is:

```text
Request Options Access
```

It uses the existing canonical manual Options onboarding path generated by:

```text
singleSystemRequestUrl("Options")
```

This is intentionally a manual request flow through Vixale Telegram. The page does not imply automatic checkout, instant activation, or automatic billing.

The public `/access` workflow remains a separate free read-only viewer-request path and is not substituted for the paid Options subscription CTA.

### Product preview contract

The public page includes a real sanitized historical Options dashboard preview sourced from the existing:

```text
'Option Journal'!A:S
```

The preview uses only the latest eligible **closed** trade and renders customer-safe journal fields such as:

- underlying;
- option contract / legs;
- expiration;
- trade type;
- contract count;
- entry date / price;
- exit date / price;
- derived recorded P/L;
- closed status;
- strategy / note when present.

The public preview does **not** expose current open Option Journal rows, journal IDs, account/customer identifiers, credentials, or private brokerage data.

The preview uses a five-minute process-local cache to bound public Google Sheets reads. If the journal cannot be loaded or no eligible closed trade exists, the page shows an unavailable state and does not substitute fabricated/sample trade data.

### English / Russian parity

English and Russian Options pages use the same structure, data-preview source, pricing/access semantics, navigation destinations, and responsive layout. Russian copy is supplied by the same Options sales refinement according to the request host; the existing Russian localization layer continues to own the broader site locale flow.

The page includes direct product-family navigation among:

```text
Day Trading
Swing Trading
Options
```
